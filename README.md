# КМДПС · Курсова робота · Варіант B3

Імітаційна модель системи передавання пакетів A–B–C (з резервним каналом у вузлі B) на основі стохастичної мережі Петрі. Час у мілісекундах.

## Файли

- `petri.py` — загальний алгоритм імітації стохастичної мережі Петрі (позиції, переходи, затримки, пріоритети, ймовірності, багатоканальні переходи).
- `model.py` — мережа Петрі варіанта B3 і збір статистики.
- `experiment.py` — верифікація, 25 незалежних повторів для кожного сценарію, пілотні траєкторії.
- `waiting.py` — розподіл часу очікування й перевірка площі черги.
- `analysis.py` — перехідний період, кількість прогонів, регресія, дисперсійний аналіз, критерій χ².
- `summarize.py` — довірчі інтервали за незалежними повторами.
- `protocol.py` — фрагменти протоколу подій.
- `figures.py` — рисунки (схеми мережі Петрі та графіки результатів).

## Запуск

Потрібен Python 3.10 або новіший. `model.py`, `experiment.py`, `waiting.py`, `summarize.py` і `protocol.py` працюють на стандартній бібліотеці; для `analysis.py` та `figures.py` потрібні пакети з `requirements.txt`.

```sh
pip install -r requirements.txt
```

Один прогін моделі (показники друкуються у форматі JSON):

```sh
python model.py --seed 3303 --high 20
python model.py --seed 3303 --high 20 --band 5
```

`--high` — поріг черги, за якого вмикається резерв; `--band 5` вимикає резерв лише тоді, коли черга опуститься нижче `high − 5` (у другому прикладі резерв вмикається при 20 і вимикається нижче 15).

Усі експерименти курсової (результати записуються в `data/`, рисунки в `media/`):

```sh
python experiment.py
python waiting.py
python analysis.py
python summarize.py
python protocol.py
python figures.py
```
